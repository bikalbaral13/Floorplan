Build from Deck
runner: …

1 · The deck

Upload the plan-phase deck — PowerPoint (.pptx) or PDF. It is saved in the project's inputs/decks/.

2 · Questions

What the deck cannot settle by itself. Your answers go to Claude and to the next stages.

3 · Room brief

The draft collects everything the deck says about the room; Claude types each item's params (curated); finalize checks every slide is covered.

4 · Plan geometry

Claude traces walls and openings on the deck's plan (trace.px.json); the script scales and checks them against the zone outlines.

5 · Objects & materials

Each brief item bound to a library object with its real parameters and a material.

6 · Room canvas

Every object placed on the canvas with the deck's spec values. Open it in the editor to check.

7 · Drawings

Plan, RCP, elevations and schedules drawn from the baked 3D model (DXF + PDF + PNG).

Runner

Script stages run on a machine with Python: node tools/runner/worker.mjs in the Floorplan repo. Jobs wait here until it picks them up.
