# Author the six-node flow

Work in a repo scratch folder `tools/tmp-<object>/` with three files (copy `tools/tmp-chair/` as the template):

```
expr.txt     the Math Engine body — plain text, commented like bed.json
build.mjs    props + slots + rows + Material nodes + edges + description → out/<name>.json
check.mjs    evaluate, time, validate, optional OBJ   (see parametric-object-creator-scripts)
```

## File shape

```json
{
  "version": 1, "id": "<name>-with-math", "title": "<Name> (mesh) — <one-line what>",
  "category": "Furniture",
  "object": { "hostKind": "node", "name": "<Name>", "units": "m", "icon": { "paths": ["<24px svg paths>"] } },
  "description": "<see below>",
  "nodes": [
    { "id": "geo",   "data": { "tool": "source",      "params": { "grabFromSelection": true, "id": "", "nodeLabel": "Geometry" } } },
    { "id": "props", "data": { "tool": "input-props", "params": { "props": [ … ] } } },
    { "id": "math",  "data": { "tool": "expr",        "params": { "name": "<Name> maths", "expr": "<expr.txt>" } } },
    { "id": "out",   "data": { "tool": "output",      "params": { "slots": [ { "id": "s1", "label": "Shell — mesh" }, … ] } } },
    { "id": "r2d",   "data": { "tool": "render-2d",   "params": { "prims": [ { "id": "p2_seat", "kind": "polygon", "name": "Seat", "color": "#…", "layer": "<Name>", "show": true } ] } } },
    { "id": "r3d",   "data": { "tool": "render-3d",   "params": { "prims": [ { "id": "p3_seat", "kind": "polyhedron", "name": "Seat", "color": "#…", "layer": "<Name>", "x": 0, "y": 0, "z": 0, "show": true } ] } } },
    { "id": "mat_leather", "data": { "tool": "material", "params": { "path": "Materials/Finishes/leather-cream.json" } } }
  ],
  "edges": [ … ]
}
```
Give nodes `position`s in columns (−960, −640, −200, 240, 620, 900; materials at y −360/−220) so the flow
opens readable.

## Edges (all generated)

| From | To | Handles |
|---|---|---|
| geo | props | `val-points` → `valin-P` |
| props | math | `val-<propId>` → `valin-<propId>` for every NON-text prop (and `P`) |
| math | out | `val-<exprName>` → `valin-s<k>` for every published name |
| out | r2d / r3d | `val-s<k>` → `valin-<rowId>` |
| mat_* | r3d | `mat` → `matin-<rowId>` (one Material node can feed several rows) |

Every wired prop must appear as a free variable in the body, or its edge dangles. Text props
(`material`, `semantics`, `materialPath`, `finishes`) are carried, NOT wired.

## Props — the standard set, then the object's own

Always: `P` (text `"[[0, 0]]"`), the object's dimensions, `rotation`, `anchorDir` (9 options), `fitMode`
(`Off|Max|Exact`, default Off), `margin`, `flipSide`, `detail` (`Blocky|Medium|Fine|Smooth`, default Fine),
`edgeCharacter` (`Crisp|Soft|Plump`), and the four text props:

- `material` — prose, for people and for prompts;
- `semantics` — the precise name from `study-the-reference`;
- `materialPath` — default material, relative to `Materials/` (e.g. `Finishes/leather-cream.json`);
- `finishes` — per-row: `"Legs=Finishes/light-oak.json; Seat=Finishes/leather-cream.json"`, matched as a
  case-insensitive substring of the 3D row NAME.

Then object-specific props: styles as selects (`armStyle`, `quilting`), counts as ranges with step 1, sizes in
metres with sensible min/max/step. **A rewritten object keeps an old id only if its meaning is identical**;
otherwise invent a new id (the chair renamed `backHeight` → `backTop`, `seatThk` → `cushionThk`,
`arms` → `armStyle`).

## The expression body

### 1. The standard preamble (copy verbatim from chair.json / bed.json)

Host frame (`_e1 … _vy`), host extent (`_Qu … _hostW`), fit (`_availL … scale`, `_s = scale`), anchor
(`_bodyL, _bodyW, _anchorL … _cu, _cv`). **Do not reuse its private names** (`_ax _ay _bx _by _cu _cv _hv0
_np _W _L _FL`) for anything else — the old chair overwrote `_ax` inside a loop.

### 2. Local frame

Author everything in the object's own `(u, v, z)`: u = depth axis with the BACK at −u, v across, z up, all
lengths `× _s`. Centre the footprint on (0, 0).

### 3. Parts — one block per part, each ending in a local face list

`Solid.SoftBox` + `Solid.Skin`, custom lofts, `msweep`, `mlathe` … as chosen. Rules:

- **Face-id hygiene.** Grouping is by RUNS of equal id. Several solids in one row need distinct id blocks:
  `Solid.Skin(sec, i * 100000)`; offset a sweep's ids `col(M,3) + 1000000` before `vcat`.
- **One row per material**, and one row per part the user may want to restyle.
- **A switched-off part is `zeros(0, 4)`**, not an error. Use `cond ? A : zeros(0, 4)`.
- **Winding**: stack loft sections so the signed volume is POSITIVE; if a ring comes out the wrong way,
  reverse it with `sortby(M, 0 - arange(rows(M)))` — decide from the ring's shoelace area, not by eye.

### 4. The frame rule — once per part, at the end

```
_pU = _cu + col(_PART, 0)
_pV = _cv + col(_PART, 1)
Part3D = hcat(_pU * _ux + _pV * _vx, _pU * _uy + _pV * _vy, col(_PART, 2), col(_PART, 3))
```
Columns 2 and 3 ride through untouched — the face id must survive.

### 5. Plan rows (2D) — derived, cheap

`[x, y, group]`, one ring per group, frame rule applied. Use the part's OUTLINE (a seat ring, a shell band,
four foot circles), never its triangles. One 2D row per part: a grouped list is read even-odd, so a part
inside another in the same row becomes a hole.

### 6. Metrics — from small vectors

`overallWidth`, `overallDepth`, `overallHeight`, key heights, `footprint`, `scale`, `meshFaces`
(computed from the counts you chose: a skin of S sections × N points is `2 + (S−1)·N` faces). **Never**
`max(col(bigMesh, k))` — compute extents from the per-station columns (see the hard rules).

## Language facts that bite

- `a ? b : c` tests a SCALAR (a matrix's [0][0]). Per element, use `where(mask, A, B)`.
- There is **no `M[i, j]` indexing** — `Q[i, 10]` silently returns the whole matrix. Use `sub(M, r, c, nr, nc)`,
  `row(M, i)`, `col(M, j)`.
- `min`, `max`, `pow`, `sin`, `abs`, `sqrt`, `sign` broadcast element-wise (scalar with matrix is fine);
  `min(M)` / `max(M)` with ONE argument reduce.
- `shift(M, -1)[i] = M[i+1]` and it WRAPS. `sortby(M, key)` permutes rows. `compress(M, mask)` drops rows.
- `arclen(P)` → cumulative length column; `resample(P, n)` → n points evenly spaced in arc length (open path;
  for a closed ring append the first point, resample n+1, drop the last).
- Loops: `loop i in N:` … `end`. Keep them for per-PART work (4 legs, N pillows), never per point.
- Names starting with `_` are private; everything else is published and can be wired to an Output slot.
- Strings compare with `==` (`detail == 'Fine'`). Comments start with `#`.
- `fitMode: Exact` scales the WHOLE object uniformly — heights too. Never rely on it to stretch one axis.

## The description

Same register as bed.json: what it is, how to host it, WHAT IT BUILDS (parts), one paragraph per
non-obvious technique and WHY it was chosen, the detail dial, DIMENSIONS AT THE DEFAULTS (measured by
check_object.mjs, not guessed), WHAT THIS CANNOT DO. Plain text, no markdown, no backticks.

## Before publishing

`node tools/tmp-<object>/build.mjs && node tools/tmp-<object>/check.mjs` must print `PASS` at the defaults
AND at each extreme of every select prop (`--set detail=Blocky`, `--set armStyle=Armless`, …) and at
min/max of the main dimensions. Then back up the old R2 file locally (if rewriting) and upload.
