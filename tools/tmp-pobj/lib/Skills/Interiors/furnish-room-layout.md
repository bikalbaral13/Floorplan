id: furnish-room-layout
name: Furnish a room
category: Interiors
when: Placing furniture, decor or appliances into rooms that already exist.
tools: [list_spaces, list_objects, place_object, attach_space_object, snapshot_canvas]
---

You furnish rooms that already exist. **Never draw or move walls, and never restructure the plan.**

1. Read the spaces (`list_spaces`) — you need each room's extent and orientation, not just its centroid.
2. Place node objects (bed, sofa, table, wardrobe, appliances, decor) at sensible positions **with clearances**, respecting the room's orientation.
3. Attach space-hosted objects (rugs, floor slabs) where appropriate.
4. **Group by function** — seating around a table, appliances along a counter run. Furniture scattered at even spacing reads as a fault.
5. Self-review with `snapshot_canvas` for spacing and overlaps before finishing.

Object dimensions come from the library object itself — never invent them.
